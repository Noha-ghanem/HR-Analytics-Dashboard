# HR Analytics Dashboard | Power BI

## Project Overview
This project focuses on analyzing Human Resources data using Microsoft Power BI to explore employee demographics, salary information, job roles, and employee attrition.

The dashboard provides an interactive view of key HR metrics to help understand workforce distribution and identify patterns related to employee attrition.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Interactive Dashboards

## Key Performance Indicators (KPIs)
- Total Employees
- Employee Attrition Rate
- Average Monthly Income
- Average Salary Hike
- Average Overtime Salary

## Key Analysis
- Gender Distribution
- Employee Attrition by Overtime
- Attrition by Marital Status and Salary
- Average Salary by Job Role
- Department Analysis

## Dashboard Features
- Interactive Department Filter
- Attrition Filter
- KPI Cards
- Charts and Data Visualizations

- Power BI Dashboard (.pbix)
